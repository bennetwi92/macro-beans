# Replay-Tool

The replay tool will be a streamlit app that I will use to load data from interactive brokers using the tws api and then simulate trading so that i can practice day trading after the fact.

## Language and Technology

Python will be used as the main language. The app will be written in streamlit. We will connect to Interactives Brokers TWS API to fetch the data. We will store this in MongoDB in a "replay" database.
